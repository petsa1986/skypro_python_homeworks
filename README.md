## Требования

Перед началом работы убедитесь, что у вас установлены следующие инструменты:

- [Python 3.6+](https://www.python.org/downloads/)
- [pip](https://pip.pypa.io/en/stable/installation/)
- [Postman](https://www.postman.com/downloads/) (для тестирования API)

## Установка

1. Клонируйте репозиторий:
    ```bash
    git clone <URL-вашего-репозитория>
    cd <имя-папки>
    

2. Установите необходимые библиотеки:
    
    pip install -r requirements.txt
    

## Запуск тестов

Чтобы запустить тесты, используйте команду:

pytest <путь-к-файлу-с-тестами>

Например, чтобы запустить все тесты в проекте, используйте:

pytest Lesson10/




## Использование Postman

Postman — это инструмент, который позволяет тестировать API. Вот как вы можете использовать его для работы с API:

1. Откройте Postman.
2. Создайте новый запрос.
3. Выберите метод (GET, POST, PUT и т.д.) в зависимости от того, что вы хотите сделать.
4. Введите URL-адрес API, например: https://x-clients-be.onrender.com/api-v2/projects.
5. Если метод требует тела запроса, выберите вкладку "Body" и введите данные в формате JSON.
6. Нажмите "Send" для отправки запроса и просмотрите результаты.
